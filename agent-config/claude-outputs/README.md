## Per-Session Output Log Naming Convention

When Claude generates code or content in a working session, create a log file here:

```
[phase]-[YYYY-MM-DD]-output.md
```

Examples:
- `phase-1-2026-03-09-output.md` — Phase 1 scaffold session
- `phase-2-2026-03-15-output.md` — Phase 2 data layer session

## What to Record in a Session Log

- Session date and model used
- Files generated (with paths)
- Key architectural decisions made
- Prompts used (summary)
- Anything that deviated from the overall plan
